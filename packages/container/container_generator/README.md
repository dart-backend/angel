An alternative container for Angel3 that uses `reflectable` package instead of `dart:mirrors` for reflection. However, `reflectable` has more limited relfection capabilities when compared to `dart:mirrors`.

## Usage

* Add `reflectable_builder` to your `dev_dependencies`.
* Annotate the class with `@contained`.
* Run `dart run build_runner build <Your class directory>`
* Alternatively, create a `build.yaml` file with the following content, then run `dart run build_runner build`

    ```yaml
    targets:
      $default:
        builders:
          reflectable_builder:
            generate_for:
              - bin/**_controller.dart
            options:
              formatted: true
    ```

## Known limitation

* Reflection on functions/closures is not supported
* Reflection on private declarations is not supported
* Reflection on generic type is not supported

## Development

The tests use `test/reflector_test.reflectable.dart`, which is generated by `reflectable_builder` and checked in. Regenerate it whenever you change the `@contained` classes in `test/reflector_test.dart`.

`reflectable_builder` cannot be added to this repository's workspace: it requires an older `analyzer` and `build` than other workspace packages (e.g. `angel3_serialize_generator`). Generate the file from a standalone copy of the two container packages instead. From the repository root:

```bash
REPO=$(pwd)
SCRATCH=$(mktemp -d)
cp -r packages/container/container packages/container/container_generator "$SCRATCH"
cd "$SCRATCH"
rm -rf container/.dart_tool container_generator/.dart_tool container_generator/pubspec.lock

# Resolve the copies on their own, with the local angel3_container.
sed -i '/^resolution: workspace/d' container/pubspec.yaml container_generator/pubspec.yaml
cat >> container_generator/pubspec.yaml <<'EOF'
dependency_overrides:
  angel3_container:
    path: ../container
EOF

cd container_generator
dart pub add --dev reflectable_builder
cat > build.yaml <<'EOF'
targets:
  $default:
    builders:
      reflectable_builder:
        generate_for:
          - test/reflector_test.dart
        options:
          formatted: true
EOF
dart run build_runner build
dart test
cd "$REPO"
```

Then copy the generated file back and check that the tests pass in the workspace:

```bash
cp "$SCRATCH/container_generator/test/reflector_test.reflectable.dart" packages/container/container_generator/test/
cd packages/container/container_generator
dart format test
dart test
```
